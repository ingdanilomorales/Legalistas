# Contexto de `app/static`

Esta carpeta contiene los recursos estáticos de la interfaz de Legalistas.

## Contenido futuro

- Hoja de estilos complementaria a Bootstrap.
- JavaScript mínimo para mejorar validaciones visuales o interacción de formularios.
- Íconos o imágenes locales, solo cuando sean necesarios.

## Criterios

- Bootstrap debe cubrir la mayor parte del diseño general.
- Los colores de estado deben conservar buen contraste y no depender únicamente del color.
- La lógica principal debe ejecutarse en el backend para que los datos sean consistentes.
- No incluir credenciales, datos personales reales ni archivos CSV en esta carpeta.
