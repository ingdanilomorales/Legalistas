# Contexto de `docs`

Esta carpeta concentrará la documentación funcional y operativa del proyecto.

La guía central de lógica y arquitectura para consulta rápida está en [../documentacion/README.md](../documentacion/README.md).

## Documentos técnicos disponibles

- [ARQUITECTURA_TECNICA.md](ARQUITECTURA_TECNICA.md): capas y decisiones generales.
- [FLUJO_FORMULARIO_CSV.md](FLUJO_FORMULARIO_CSV.md): recorrido de formularios y resultados.
- [DISENO_CSV.md](DISENO_CSV.md): columnas, tipos y reglas de integridad.
- [BACKEND.md](BACKEND.md): archivos y funciones generales previstas.
- [DECISIONES.md](DECISIONES.md): reglas adoptadas y puntos pendientes.

## Documentos recomendados

- Reglas de negocio de cuotas y vencimientos.
- Diccionario de campos de cada CSV.
- Manual de uso local.
- Procedimiento de respaldo y recuperación.
- Decisiones pendientes y supuestos.
- Casos de prueba manuales.

La documentación debe registrar cualquier cambio en la regla del pie del 30%, la fecha de vencimiento del día 30 y la forma de calcular la proyección mensual.
